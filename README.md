# Full Stack Placement Preparation Portal

A comprehensive placement preparation platform built with the MERN stack (MongoDB, Express, React, Node.js).

## 🚀 Features

- **User Authentication** - Secure login/signup with JWT
- **Company Listings** - Browse and filter placement opportunities
- **Practice Problems** - Coding questions with difficulty levels
- **Admin Dashboard** - Manage users and content
- **Progress Tracking** - Track your preparation journey

## 🛠️ Tech Stack

**Frontend:**
- React.js
- Tailwind CSS
- Vite

**Backend:**
- Node.js
- Express.js
- MongoDB

## 📦 Installation

```bash
# Clone the repository
git clone https://github.com/deeptismitab-ship-it/Full_Stack_Placement_Preparation_Portal.git
cd Full_Stack_Placement_Preparation_Portal

# Install backend dependencies
cd backend
npm install

# Install frontend dependencies
cd ../frontend
npm install
```

## ⚙️ Configuration

Create a `.env` file in the backend directory:

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
```

## 🚀 Running the Application

```bash
# Start backend (from backend directory)
npm run dev

# Start frontend (from frontend directory)
npm run dev
```
